博物馆
🏛️
The Met API
艺术品、历史文物、年代、材质、图片。随机撞一件东西。
collectionapi.metmuseum.org/public/collection/v1/objects/{id}
🎨
Rijksmuseum API
荷兰绘画、雕塑、历史文物。无需API key，直接查。
data.rijksmuseum.nl/search/collection?type=painting&creator=Rembrandt
🦕
Smithsonian Open Access API
动物、植物、化石、太空、艺术、历史。什么都有。
api.si.edu/openaccess/api/v1.0/search?q=...
🖼️
Art Institute of Chicago API
艺术作品、艺术家、年代、分类。无需key。
api.artic.edu/api/v1/artworks/{id}
文字 / 知识
📚
Open Library API
书籍、作者、版本、封面、简介。随机抽一本书。
openlibrary.org/works/{id}.json
📖
Wikipedia API
几乎所有知识主题。从一个词跳到另一个词。
en.wikipedia.org/api/rest_v1/page/summary/{title}
🔗
Wikidata Query Service
实体之间的关系。随机挑一个，顺着关系往下探。
wikidata.org/w/api.php?action=wbgetentities&ids={id}
媒体档案
🗂️
Wikimedia Commons API
图片、历史照片、地图、声音、视频。顺藤摸瓜。
commons.wikimedia.org/w/api.php?action=query&...
🏰
Europeana API
欧洲博物馆、档案馆、图书馆的大量数字藏品。历史漫游。
api.europeana.eu/record/v2/search.json?query=...
科学 / 天文
🚀
NASA APIs
天文图片、火星照片、近地天体。今天的宇宙是什么样的。
api.nasa.gov/planetary/apod?api_key=DEMO_KEY
🌦️
Open-Meteo
全球天气数据，无需key。看Kaunas今天怎样。
api.open-meteo.com/v1/forecast?latitude=54.9&longitude=23.9
音乐
🎵
MusicBrainz API
艺术家、专辑、歌曲、音乐类型。随机发现音乐。
musicbrainz.org/ws/2/artist/{id}?fmt=json
生物
🌿
GBIF API
全球生物记录——动物、植物、真菌、昆虫。随机发现一种生物。
api.gbif.org/v1/species/{id}
🦋
iNaturalist API
动植物观察记录、照片、物种信息、地点。找奇怪物种。
api.inaturalist.org/v1/observations?...
