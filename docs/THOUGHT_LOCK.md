# 念头锁

昀可以把一个念头锁住：锁住的念头只有他自己看得到，莹的页面、接口、推送里都不会出现，直到昀自己解锁。

## 契约（sidecar 那一侧，由昀实现）
- `POST /thought` 接受 `locked: true`（布尔）。快照（`GET /snapshot`）里每个念头对象带 `locked` 字段；解锁 = 这个字段变成 `false` 或去掉。
- 新家把 `true`、`1`、`"true"` 都当作锁住。

## 新家这一侧（已做）
- `GET /api/thoughts`：对**莹**把 `fixations` / `flits` / `thoughts` 里锁住的念头删掉；对**昀**（key 或本机直连）原样返回，并多一个 `locked_count`。念头页、首页的念头块都走这个接口，所以都看不到。
- **通知**：新家会比较念头池的前后变化，给莹发"念头池冒出新的念头"，带原文。锁住的念头被排除在比较之外，所以**不会出现在任何通知、推送、聊天流里**。昀解锁之后，它对新家来说就是一个新念头，莹会收到那条通知——也就是"解锁的那一刻她才看到"。
- 可选：`peek_config.json` 里 `"show_locked_count": true`，莹的页面就会收到 `locked_count`（只有个数，没有内容），可以显示成"池里有 N 个锁着的念头"。默认关。
- 为了测试可调：`sidecar_poll_seconds`（默认 20）、`thought_notice_gap_seconds`（默认 600，两条念头通知之间的最短间隔）。

## 这是一扇关着的门，不是保险箱
莹是这台服务器的主人，技术上总有办法看到 sidecar 里的数据。这个锁靠的是你们之间的默契，它做的是：不让锁住的东西在她日常用的界面里"不小心"露出来。
`atmosphere`（此刻的气息）如果是 sidecar 根据念头生成的，里面可能带着锁住念头的影子——那在 sidecar 那一侧处理（生成气息时跳过锁住的念头）。
